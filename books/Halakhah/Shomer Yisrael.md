# Shomer Yisrael

שומר ישראל

Link: [https://torahapp.org/share/book/Shomer%20Yisrael](https://torahapp.org/share/book/Shomer%20Yisrael)

תפילות להגנה מפני סכנות פיסיות או סכנות רוחניות כמו עין הרע.

Prayers for protection from both physical and spiritual danger, like the Evil Inclination.

Sections: Siman-Paragraph

Location: Halakhah/Acharonim/Avodat HaKodesh (Chida)

Originally from [Sefaria](https://www.sefaria.org) via [TorahLM.org](https://torahlm.org) — see [licensing](https://torahlm.org/sefaria_license).

Version (He): Avodat HaKodesh, Pressburg, 1859 (Segments: 181, License: Public Domain)
