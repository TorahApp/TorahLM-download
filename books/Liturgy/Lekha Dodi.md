# Lekha Dodi

לְכָה דוֹדִי

Link: [https://torahapp.org/share/book/Lekha%20Dodi](https://torahapp.org/share/book/Lekha%20Dodi)

פיוט שנהוג לשיר בערבי שבתות בקבלת השבת, חיברו שלמה אלקבץ, מקובל בן המאה ה-16.

Hymn sung on Friday evenings as part of Kabbalat Shabbat to welcome in Shabbat, composed by 16th-century kabbalist Shlomo Alkabetz.

Sections: Verse-Verset

Location: Liturgy/Piyutim

Originally from [Sefaria](https://www.sefaria.org) via [TorahLM.org](https://torahlm.org) — see [licensing](https://torahlm.org/sefaria_license).

Version (He): Wikisource (Segments: 38, License: CC-BY-SA)

Version (En): Sefaria Community Translation (Segments: 38)
