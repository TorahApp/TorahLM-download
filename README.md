# TorahLM-download

Torah texts as clean Markdown — for reading, downloading, and LLM ingestion
(NotebookLM, chatbots, RAG corpora). Part of [TorahLM.org](https://TorahLM.org).

A project of [TorahApp](https://TorahApp.org/download).

Generated by TorahApp's LLM data pipeline with data
from [Sefaria](https://www.sefaria.org), [Halachipedia](https://www.halachipedia.com), Dicta, and shiurim (from YUTorah, OUTorah/AllTorah, Chabad, Torahcasts, Podcasts, etc).

Do not edit files here by hand; regenerate them from the pipeline.

## Layout

```
books/                       # one Markdown file per book, categorized
  Tanakh/Genesis.md
  Tanakh/Rashi on Genesis.md
  Talmud/Berakhot.md
  Halakhah/Mishnah Berurah.md
  ...                        # 14 categories from Sefaria's taxonomy

notebooklm/                  # combined sources sized for NotebookLM (≤ ~509k words each)
  0001_About_and_Misc.md     # start here: project overview + full file index
  halachipedia/              # 02xx — Halachipedia
  books/                     # 1xxx — Sefaria books (Tanakh, Talmud, Halakhah, ...)
  shiurim/                   # 4xxx — podcast/shiur episode listings
```

Each book file contains Hebrew + approved English translations, with footnotes and
per-segment links back to `https://torahapp.org/share/book/...`.
